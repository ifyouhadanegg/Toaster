Codename:PhewBar Toast Integration Demo.

The home page links to three experiences:

- `/user`: share a celebration, switch between five demo users, and explore the beverage gifting flow.
- `/merchant`: a placeholder for the future merchant experience.
- `/admin`: a placeholder for the future PhewBar admin experience.

The user demo treats all listed merchants as being in Pacific Beach, San Diego.
Selecting that area while sharing a celebration shows the app-enabled demo locations.
Celebrations are saved in the current browser and can be edited or ended there;
they are not shared across browsers or devices. All five demo users are friends
with each other. Creating a gift produces a link to share manually; it does not
automatically deliver the gift to another persona.
